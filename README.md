## 免备案免掉的是一道流程，不是全部约束

先把边界划清楚，这几条很多文章含糊带过：

- **免掉的是 ICP 备案**。备案要求只针对大陆机房。港澳台及海外机房不在此列，所以香港、美国、日本服务器开通即可用。
- **没有免掉内容合规**。香港机房受香港本地法律约束，美国机房有 DMCA 这类规则。侵权、赌博、恶意攻击类内容一样会被投诉下线，机房不会因为你是境外用户就不处理。
- **通常没有免掉实名认证**。购买海外服务器同样要实名，这是支付和账号层面的要求，和备案是两件事。别把"免备案"理解成"什么都不用提交"。
- **免掉的部分可能会回来**。如果你的项目后面要接国内 CDN、上小程序、开公众号支付，这些渠道仍然要求域名完成备案。免备案只适合那些不需要走国内资质的场景。

## 三个真正决定体验的变量

### 线路比机房名字重要得多

同样是"香港服务器"，走三网直连和走纯国际线路，大陆访问体验能差出一大截。公开测评里，香港三网直连节点到大陆三网平均延迟在 45ms 左右，本地 ping 平均 64ms，基本无丢包；而纯国际线路的节点在高峰时段绕路更明显。

美国节点则要跨太平洋，大陆访问延迟普遍在 150ms 以上，晚高峰更容易波动。这不是某家服务商的问题，是物理距离决定的。美国节点的价值在于大带宽和面向北美、欧洲的访问速度，不在大陆访问速度。

### 限流量的大带宽，还是不限流量的小带宽

大部分海外云服务器都分这两类：

- **大带宽限流量型**：比如香港五区的国际线路款，入门档给到 200Mbps，配 1TB 流量。适合有突发带宽需求、但整月流量不算高的站点。
- **小带宽不限流量型**：上行带宽通常在 10Mbps 到 50Mbps 之间，月流量不限。适合持续有访问、但单次传输不大的博客、企业站、API 服务。

雨云这两类都提供，价格基本一致，选错的表现就是：要么每个月都在担心流量用超，要么明明不限流量却嫌带宽太窄。

### 独立 IP 和 NAT 的区别

部分区域的低配机型默认是 NAT 共享 IP，需要端口映射才能对外访问。自己玩服务没问题，但**拿 NAT 机器建站基本不现实**：域名解析、搜索引擎抓取、部分访客的网络环境都会出问题。要建站就选带独立 IP 的档位，雨云独立 IP 一般是 5 元/月，可加购多个。
